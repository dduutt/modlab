# Modbus 桌面应用 UX 与交互设计规范文档

## 概述

本规范文档详细说明了 Modbus 桌面应用程序（Tauri + Vue 3）的前端 UX 界面与交互逻辑优化设计，涵盖新增设备模态框、标签页管理与连接安全防护、数据网格按功能码区分双击行为、右键快捷菜单以及状态栏简短错误提示。

---

## 1. 新增设备模态框 (New Device Modal)

- **触发方式**：点击顶栏标签栏末尾的 `+` 按钮。
- **弹窗字段**：
  - **设备名称 (`title`)**：文本输入框，自动填充默认名称（如 `Slave 2`、`Master 1`），支持自定义修改。
  - **设备类型 (`role`)**：单选按钮，选择 `Slave` (从站) 或 `Master` (主站)。
- **提交行为**：
  - 点击“确认”按输入的名称与类型即时创建新会话标签页，初始使用默认通信参数；
  - 点击“取消”或右上角 `X` 按钮关闭模态框。

---

## 2. 标签页管理与关闭防护 (Tab Management & Safety)

- **双击内联重命名**：
  - 双击标签页标题文字直接切换为内联 `<input>` 输入框；
  - 按 `Enter` 键或失焦时保存更新后的设备名称。
- **关闭防护 (Safety Guard)**：
  - **未连接状态**：点击标签页的 `X` 按钮直接关闭会话；
  - **已连接通信状态**：点击 `X` 按钮弹出安全确认对话框：
    > “设备正在通信中，确定要断开连接并关闭吗？”
  - 点击确认后断开通信连接并销毁该会话标签页。

---

## 3. 数据网格与功能码联动 (Data Grid & Function Linkage)

### A. 按功能码区分双击行为
- **线圈/离散量 (`0x01` / `0x02`)**：
  - 双击单元格直接在 `0` 和 `1` 之间快速翻转切换；
  - 单元格数值为 `1` 时显示为高亮绿色激活标签；
  - 不唤起任何弹窗或文本输入框。
- **寄存器 (`0x03` / `0x04`)**：
  - 双击单元格唤起内联 `<input>` 输入框编辑数值；
  - 匹配当前会话的进制格式（`Dec` 或 `Hex`）。

### B. 功能码与 Format 下拉框联动 (`ConfigRow.vue`)
- 选择 `0x01` / `0x02` 功能码时：Format（格式）下拉选择框自动禁用；
- 选择 `0x03` / `0x04` 功能码时：Format 下拉选择框恢复启用，允许在 `Dec` 与 `Hex` 之间自由切换。

### C. 右键快捷菜单 (Context Menu)
- 右键点击网格任意单元格弹出自定义菜单：
  1. 📋 **复制数值 (Copy Value)**：复制单元格当前文本至剪贴板；
  2. ✏️ **修改数值 (Edit Value)**：触发寄存器编辑或翻转线圈状态；
  3. 🧹 **清零 (Reset to 0)**：将目标单元格数值重置为 `0`。

---

## 4. 工具栏与状态栏反馈 (Toolbar & Status Bar)

### A. 工具栏反馈
- **Connect 按钮 Loading 状态**：连接握手过程中显示转圈 Loading，防重复点击。
- **只读功能码禁用**：当功能码为只读的 `0x02` 或 `0x04` 时，`Random` 和 `Increment` 按钮呈灰化禁用状态，悬浮提示“只读功能码不可写入”。

### B. 状态栏简短提示 (底部左下角)
- 当发生连接失败或通信异常时，**直接在底部左下角状态栏显示简短明确的错误提示**（例如：`[Slave 2] 连接失败: COM1 端口被占用`）。无需鼠标悬浮 Tooltip。

---

## 5. 显式排除的特性 (Non-Requirements)

- **无主题切换**：保持干净整洁的默认浅色主题，无需深色模式。
- **无键盘快捷键**：所有操作通过鼠标与界面按钮完成。
- **无报文抓包抽屉**：本阶段暂不涉及报文抓包面板设计。
